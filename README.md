# Techos BESS

App web para analizar cubiertas industriales con OpenStreetMap, estimar los MWp fotovoltaicos instalables, dimensionar contenedores BESS de 5 MWh y calcular el ahorro potencial.

Abrir: https://crosboss.github.io/Techos-bess/

- Huellas de edificios: Overpass API (OpenStreetMap)
- Geocodificación: Photon / Nominatim
- Ortofoto: Esri World Imagery
- Todo el cálculo es en el navegador; los supuestos son editables en el panel.
